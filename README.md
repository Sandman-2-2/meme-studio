# 😎 Meme Studio

A personal meme maker with classic templates, AI captions (Google Gemini), a drag-and-drop caption editor, multi-panel builder, AI scene generator, and a local vault.

**Live site:** https://sandman-2-2.github.io/meme-studio/

## Using it
- Tap **Add AI key** (top right) and paste a free Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey). The key is stored only in your browser, never in this repo.
- Classic templates load live from imgflip.com.
- On iPhone/Android: open the site, then Share → **Add to Home Screen** for an app icon.

## Files
| File | Purpose |
|---|---|
| `index.html` | The whole app (HTML, CSS, JS) |
| `manifest.webmanifest` | Installable app name, colors, icons |
| `apple-touch-icon.png` | iPhone/iPad home screen icon (180×180) |
| `icon-192.png`, `icon-512.png` | Android / Chrome app icons |
| `favicon-32.png` | Browser tab & bookmark icon |
| `icon.svg` | Source artwork for the icon |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |
